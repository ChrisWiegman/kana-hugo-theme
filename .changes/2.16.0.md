## 2.16.0 - 2026-11-11

### Features

* Serve content, featured, and asset-image images as AVIF with a WebP fallback in a <picture>, which roughly halves image weight. Configure the formats with params.imageFormats (default ["avif", "webp"]) and set [imaging.avif] quality in the site config (60 is recommended).

### Bug Fixes

* Skip ancestors without a page of their own (such as an unrendered posts section) in JSON-LD breadcrumbs instead of listing them with an empty URL.

### Chores

* Trim repeated head markup from every page but the home page. rel="me" links and the author's sameAs profiles, plus the site's description, language, publisher, and search action in JSON-LD, now appear only on the home page.
