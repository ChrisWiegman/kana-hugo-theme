## 2.13.0 - 2026-11-11

### Features

* The library page now ships only the first batch of books as HTML and loads the full list from a fingerprinted JSON file in the background, keeping only the books on screen in the DOM. Without JavaScript it links to the Markdown version for the full list.

### Chores

* Add end-to-end tests for progressive library loading, sorting the full library, remembered sorts, clicks made before the data loads, a failed data request, and the page without JavaScript.
