## 2.14.0 - 2026-11-11

### Breaking Changes

* The syntax highlighting stylesheet now only colors the Chroma token classes used on chriswiegman.com; other tokens use the base code color.

### Features

* Shrink the stylesheet every page loads by moving rules the homepage never uses (figures, post lists, pagination, and post-only mobile styles) into the page stylesheet and removing redundant and unreachable rules. The homepage CSS is about 30% smaller (20% gzipped).
* Load the draft post styles only on the homepage during development, the only place drafts are listed.
* Publish a Markdown version of the homepage (add "markdown" to outputs.home) with its intro, the 10 most recent posts, and a link to the archive, linked from the homepage head like other pages.

### Bug Fixes

* Remove the link underline from note titles on the notes archive page.
* Keep the homepage hero image at its full width while it loads, so the intro text and recent posts no longer shift when it appears.
* Remove the mobile rule that tried to stack the search form into one column; the archive form styles always overrode it, so it never applied.
* Markdown front matter and the Markdown alternate link's title fall back to the site title for pages without one, such as a homepage whose _index.md sets no title.

### Chores

* Add an end-to-end test that the homepage hero image keeps its width before it loads.
