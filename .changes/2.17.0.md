## 2.17.0 - 2026-11-11

### Features

* Publish agent discovery files, each opt-in through outputs.home: an Agentic Resource Discovery manifest ("ard") at /.well-known/ard.json and /.well-known/ai-catalog.json listing the site's machine-readable resources, with an Agentmap line in robots.txt and rel="ard" links; an RFC 9727 API catalog ("apicatalog") at /.well-known/api-catalog with an OpenAPI 3.1 description of the read-only static endpoints at /openapi.json; and a website-only Personal Agent Protocol declaration ("poppy") at /.well-known/poppy.json. Add other resources to the manifest with params.ard.entries.
* Register WebMCP tools so agents in the browser can search the site (search_site) and read any page as Markdown (get_page_markdown), and mark up the search form with declarative WebMCP attributes. The script loads whenever the JSON search index is enabled and does nothing in browsers without WebMCP; set params.webmcp = false to leave it out.
* Add a read-only MCP server for Cloudflare Workers (workers/mcp.mjs) with search_site, list_recent_posts, and get_page tools answered from the site's static files, and an "mcpcard" output that publishes its MCP Server Card at /.well-known/mcp/server-card.json and lists it in the ARD manifest and agent skill. Search index entries now include kind ("post" or "page").
