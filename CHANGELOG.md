# Changelog
All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html),
and is generated by [Changie](https://github.com/miniscruff/changie).

## 2.19.0 - 2026-11-11

### Features

* Load an optional site stylesheet. A site that adds assets/scss/site.scss gets it compiled, fingerprinted, and linked on every page after the theme's styles, so it can style its own content without inline style attributes and keep a strict style-src 'self' Content Security Policy.

## 2.18.0 - 2026-11-11

### Features

* Add a read-only A2A agent at /a2a to the Worker, now workers/agents.mjs (workers/mcp.mjs still works). It speaks the JSON-RPC binding for A2A 1.0 and 0.3, replies to each message at once with search results, recent posts, or a page as Markdown, and keeps no tasks. Add an "agentcard" output that publishes its Agent Card at /.well-known/agent-card.json and lists it in the ARD manifest and agent skill. Route /a2a to the Worker with assets.run_worker_first.

## 2.17.1 - 2026-11-11

### Bug Fixes

* Stop loading the WebMCP script on every page. It added a JavaScript request for every visitor while doing nothing in browsers without WebMCP. The search form keeps its declarative WebMCP attributes, which need no JavaScript, and the MCP server (workers/mcp.mjs) offers the same tools to agents.

## 2.17.0 - 2026-11-11

### Features

* Publish agent discovery files, each opt-in through outputs.home: an Agentic Resource Discovery manifest ("ard") at /.well-known/ard.json and /.well-known/ai-catalog.json listing the site's machine-readable resources, with an Agentmap line in robots.txt and rel="ard" links; an RFC 9727 API catalog ("apicatalog") at /.well-known/api-catalog with an OpenAPI 3.1 description of the read-only static endpoints at /openapi.json; and a website-only Personal Agent Protocol declaration ("poppy") at /.well-known/poppy.json. Add other resources to the manifest with params.ard.entries.
* Register WebMCP tools so agents in the browser can search the site (search_site) and read any page as Markdown (get_page_markdown), and mark up the search form with declarative WebMCP attributes. The script loads whenever the JSON search index is enabled and does nothing in browsers without WebMCP; set params.webmcp = false to leave it out.
* Add a read-only MCP server for Cloudflare Workers (workers/mcp.mjs) with search_site, list_recent_posts, and get_page tools answered from the site's static files, and an "mcpcard" output that publishes its MCP Server Card at /.well-known/mcp/server-card.json and lists it in the ARD manifest and agent skill. Search index entries now include kind ("post" or "page").

## 2.16.0 - 2026-11-11

### Features

* Serve content, featured, and asset-image images as AVIF with a WebP fallback in a <picture>, which roughly halves image weight. Configure the formats with params.imageFormats (default ["avif", "webp"]) and set [imaging.avif] quality in the site config (60 is recommended).

### Bug Fixes

* Skip ancestors without a page of their own (such as an unrendered posts section) in JSON-LD breadcrumbs instead of listing them with an empty URL.

### Chores

* Trim repeated head markup from every page but the home page. rel="me" links and the author's sameAs profiles, plus the site's description, language, publisher, and search action in JSON-LD, now appear only on the home page.

## 2.15.0 - 2026-11-11

### Features

* Publish an Agent Skills discovery index (add "agentskills" to outputs.home) at /.well-known/agent-skills/index.json with one skill that tells agents how to read, search, and cite the site, including its content signals and license. The skill's SHA-256 digest is computed from the published file at build time, and llms.txt links to the index. Configure it with params.agentSkills.

## 2.14.0 - 2026-11-11

### Breaking Changes

* The syntax highlighting stylesheet now only colors the Chroma token classes used on chriswiegman.com; other tokens use the base code color.

### Features

* Shrink the stylesheet every page loads by moving rules the homepage never uses (figures, post lists, pagination, and post-only mobile styles) into the page stylesheet and removing redundant and unreachable rules. The homepage CSS is about 30% smaller (20% gzipped).
* Load the draft post styles only on the homepage during development, the only place drafts are listed.
* Publish a Markdown version of the homepage (add "markdown" to outputs.home) with its intro, the 10 most recent posts, and a link to the archive, linked from the homepage head like other pages.

### Bug Fixes

* Remove the link underline from note titles on the notes archive page.
* Keep the homepage hero image at its full width while it loads, so the intro text and recent posts no longer shift when it appears.
* Remove the mobile rule that tried to stack the search form into one column; the archive form styles always overrode it, so it never applied.
* Markdown front matter and the Markdown alternate link's title fall back to the site title for pages without one, such as a homepage whose _index.md sets no title.

### Chores

## 2.12.0 - 2026-11-11

### Breaking Changes

* Require Hugo extended v0.169.0 or later.

### Features

* Add a websubHub parameter to change or remove the WebSub hub advertised in RSS feeds.
* Publish a Markdown version of each page (add "markdown" to outputs.page), linked from the page head, with the blog archive and library rendered as Markdown lists.
* Add llms.txt and llms-full.txt outputs (add "llms" and "llmsfull" to outputs.home) so LLMs and agents can find and read the site's content.
* Add optional AI crawler rules to robots.txt: Content-Signal preferences (params.robots.contentSignals) and fully blocked user agents (params.robots.blockAgents).
* Expand JSON-LD into a linked schema.org graph with the author, website and search action, breadcrumbs, Markdown links, and optional Book markup for the library (params.jsonldBooks).
* Add author meta and rel="me" profile links (params.identities, params.authorURL), and use git-based Lastmod for pages in the sitemap.
* Support optional note permalinks: when note pages are rendered, the archive and notes feed link to them, and they're marked noindex and kept out of the sitemap.
* Provide default imageSizes and imageSizeString values that match the theme's layout, including 2x image widths for high-density screens.

### Bug Fixes

* Fix the image sizes example and dev config, which used invalid "w" units in the sizes attribute so browsers ignored it and downloaded oversized images.
* Markdown images that aren't in assets/ (page bundles, static files, remote URLs, SVGs) no longer break the build; they fall back to a plain img tag.
* Responsive images are no longer upscaled past their original width, and srcset URLs are now absolute so every entry resolves correctly with relativeURLs and in RSS feeds.
* Notes RSS feed uses the configured author instead of a hard-coded name, and calculates note links from the site's pagination size instead of assuming 25.
* Replace deprecated .Params.description with .Description and remove deprecated .Scratch usage in JSON outputs.
* Search index and JSON-LD BlogPosting markup now respect mainSections instead of assuming a posts section.
* Links to the blog, search, tags, and categories no longer assume the site lives at the domain root.
* Escape titles in search results and show dates in the site's language.
* A missing headerIcon or books section now logs a warning instead of failing the build.
* Fix invalid search form attributes, the html lang attribute, and the schema.org URL; the library heading now uses the page title.
* Render the header icon and asset-image shortcode images at 2x their displayed size so they stay sharp on high-density screens.

### Chores

* Update project dependencies.
* Run e2e tests and screenshots on a dedicated port (1314) so they no longer reuse another Hugo server running on 1313.
* Lint the whole repository (tests and tooling scripts included) and run lint in CI.
* Pin the Hugo version used in CI instead of fetching the latest release, and stop concurrent CI runs on different branches from cancelling each other.
* Install a pinned gotmplfmt into ./bin so the VS Code formatter finds it, install only Chromium for tests, and make the local release zip match the GitHub release.
* Add end-to-end tests for search, the notes RSS feed, and image render hook fallbacks.
* Update README to document current tooling, front matter, and parameters.
* Document recommended imaging settings for sharper processed images and use them in the development site.
